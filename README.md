Task 1
Restaurant Ordering System 
Create a simple Restaurant Ordering System using HTML, CSS,
and JavaScrip
Requirements
Part 1 — Customer Information
Ask the user to enter
Name
Age
Gender
The gender should be male or female
Display a welcome message
Male →
 Welcome Mr. [Name]
Female →
 Welcome Ms. [Name]
Any other input →
 Welcome [Name]
Part 2 — Check Customer Eligibility
Check the customer's age
If the age is less than 16
Display "You are not eligible to place an order“
If the age is 16 or above
Continue with the order
Part 3 — Choose an Order
Ask the user to enter one of the following
Burger
Shawarma
Zinger
Check the entered order
If the order is one of the available options
Your order is being prepared
Otherwise
.Invalid order. Please try again
Part 4 — Logical Operators
Add the following rules
If the customer is 18 or older AND has a valid order
Display "Order confirmed“
If the customer is under 18 OR the order is invalid
Display "Order requires verification“
Use logical operators such as
&&
||
!
Part 5 — Display the Information
Use
alert() to display important messages
console.log() to display the customer's information
document.write() to display a final order summary on the page
The final summary should contain
Customer Name
Age
Gender
Order
Order Status
Extra Challenge
Add a variable called isAvailable
If the selected order is available
isAvailable = true
If it is not available
isAvailable = false
Use the variable with a condition to determine whether the
order can be prepared
Important
Do not use arrays, functions, loops, objects, DOM manipulation,
or other concepts that have not been taught yet
The solution should mainly use
Variables + User Input + Output + Comparison Operators +
Conditions + Logical Operators
